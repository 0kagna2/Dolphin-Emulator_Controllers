# Dolphin Controller Profiles
Repositorio dedicado a recopilar configuraciones de mandos para Dolphin Emulator en Windows, facilitando el uso de diferentes controladores en juegos de Nintendo Wii.

🎮 Mandos compatibles

Xbox Series X|S Controller

Razer Raiju (PS4 / PC)

PlayStation 4 DualShock 4

PlayStation 5 DualSense

📁 Contenido

Cada mando dispone de su propio archivo .ini, con una configuración de botones, sticks analógicos, gatillos y cruceta adaptada para ofrecer una experiencia cómoda de juego.

🎯 Juegos

Las configuraciones están orientadas principalmente a juegos de Wii, especialmente Super Smash Bros Brawl.

⚙️ Instalación

Descarga el archivo .ini correspondiente a tu mando.

Copia el archivo en la carpeta de perfiles de Wii de Dolphin.

Abre Dolphin Emulator.

Accede a Mandos > Wii Remote emulado > Configurar.

Selecciona el perfil correspondiente y pulsa Cargar.

💻 Plataforma

Sistema operativo: Windows.

Emulador: Dolphin Emulator.

Formato de configuración: INI.

📝 Notas

Los perfiles pueden necesitar pequeños ajustes dependiendo del modelo del mando, la conexión utilizada (USB o Bluetooth) y el dispositivo de entrada detectado por Dolphin.

Repositorio comunitario y abierto a mejoras y nuevas configuraciones.
